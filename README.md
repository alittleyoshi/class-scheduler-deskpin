# class-scheduler-deskpin

一个基于 **Python** 的 Windows 小工具，启动后会在桌面显示一个 **无边框悬浮窗口**，并在系统托盘驻留。  
它的主要功能是：根据你设置的课程/时间表，在窗口中显示当前状态和时间，方便随时查看。  

---

## ✨ 功能特性

- 🖼️ **无边框悬浮窗口**：置顶显示，不会被其他窗口遮挡。  
- 🪟 **托盘图标**：可通过托盘菜单操作。  
- ⏰ **时间显示**：实时刷新当前时间。  
- 📅 **课程/时间安排**：通过 CSV 文件配置每日的上课/休息时间。  
- 🔔 **铃声提醒**：到时间时播放铃声（需手动放置音频文件）。

## ⚙️ 使用方法

1. **下载/运行**  
   - 将本项目打包的 `exe` 放在任意文件夹下。  
   - 在同一文件夹中准备好：  
     - **配置文件** `schedule.csv`  
     - **铃声文件**（与 CSV 中写的文件名一致）  

2. **编辑课表**  
   - 使用 CSV 文件定义每天的时间表：  
     ```csv
     period,type,start,end,sound
     1,上午第一节,08:00,08:40,class_start.mp3
     2,课间,08:40,08:50,class_end.mp3
     ...
     ```
   - `start` / `end`：开始与结束时间  
   - `type`：状态显示的文字  
   - `sound`：铃声文件名（需与 exe 同目录下的文件一致）  

3. **运行程序**  
   - 双击运行 `class-scheduler-deskpin.exe`。  
   - 程序启动后会在桌面显示悬浮窗口，并在托盘驻留。  

---

## 📌 注意事项

- 必须确保铃声文件与 CSV 中的文件名完全一致，并与 `exe` 放在同一目录下。  
- 本项目目前仅在 **Windows** 测试通过。  
- 暂不支持 UI 编辑课表，需手动修改 CSV 文件。
